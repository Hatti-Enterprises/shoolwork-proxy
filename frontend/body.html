Service Provider (Host)

Controls which sync modes are available to users of this deployment. Hosts who don't want to set up Google OAuth can switch to manual-only mode.

Full mode: Users can sign in with Google to auto-sync encrypted backups to Drive, and also export/import local .shoolwork.zip files manually.
Manual-only mode: Drive sign-in, auto-sync, and the Drive status panel are hidden. Users can still export/import encrypted .shoolwork.zip files locally. No Google OAuth credentials are required to deploy in this mode.

Advanced

Google Drive Sync

End-to-end encrypted backup of all browser storage — cookies, localStorage, sessionStorage, IndexedDB, Cache API. Encrypted with AES-256-GCM using a password-derived key (PBKDF2, 250k iterations). The Drive file is unreadable without your password.

What kind of code do I have?

8-character code (e.g. K7M2-X9P4) — invite code from the host. Works on one device only.

6-digit code (e.g. 123456) — TOTP code from your authenticator app (Authy, Google Authenticator, 1Password). Rotates every 30 seconds.
